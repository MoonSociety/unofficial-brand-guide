# Contributing

Thanks for helping maintain the (unofficial) Moon Society brand archive. This
repo is consumed by AI agents, build pipelines, and designers, so the most
important rule is: **`brand.json` is the single source of truth, and everything
else is generated or kept consistent with it.**

## The golden rule: edit `brand.json` first, then regenerate

`colors.css`, `colors.json`, `tokens.json`, and `llms.txt` are **generated** —
do not hand-edit them. The flow for any brand value change (a color, a font, a
token, a logo rule, voice guidance) is:

```bash
# 1. Edit the source of truth
$EDITOR brand.json

# 2. Regenerate the derived files
node scripts/generate-derived.mjs

# 3. Validate (schema + recomputed accessibility ratios)
node scripts/validate-manifest.mjs

# 4. Build the site to catch broken references (optional but recommended)
cd site && npm install && npm run build
```

CI runs steps 2–3 for you and **fails the build** if a derived file is out of
sync with `brand.json` (`generate-derived.mjs --check`) or if an accessibility
ratio in `brand.json` doesn't recompute correctly. So if CI is red, run
`node scripts/generate-derived.mjs` and commit the result.

## What lives where

| File | Edit by hand? | Notes |
|---|---|---|
| `brand.json` | ✅ yes | The source of truth. Validated by `schemas/brand-v2.json`. |
| `colors.css`, `colors.json`, `tokens.json`, `llms.txt` | ❌ no | Generated by `scripts/generate-derived.mjs`. |
| `moon-society-brand-guide.md`, `moon-society-design-spec.md` | ✅ yes | Human narrative — keep consistent with `brand.json`. |
| `schemas/brand-v2.json` | ✅ yes | Update when you add a new manifest field. |
| `site/` | ✅ yes | Next.js showcase. Reads `public/brand.json` (synced from root). |

## Accessibility

Color contrast is verified in CI by recomputing every ratio in
`brand.json`'s `colors.accessibility` array from the two hex values. If you add
a pairing, you can put any placeholder ratio — but the build will fail unless
the stated ratio and WCAG label match the computed value, so just run
`node scripts/validate-manifest.mjs` locally and use the number it reports.

Never emit Gold (`#FFCD00`) or Dark Gold (`#D29F13`) as **text** on white —
both fail WCAG. `--ms-warning` is a fill/icon color, not a text color on light.

## Versioning

`brand.json` is SemVer (`2.x.y`, matched by the schema). Bump:
- **patch** for value corrections that don't change structure,
- **minor** for additive fields/tokens,
- **major** only with a new schema (`schemas/brand-vN.json`).

Pinned consumers can fetch an immutable snapshot at
`https://branding.moonsociety.org/v2/brand.json` (see `resources.versioned` in
`brand.json`); `…/brand.json` always tracks latest.
